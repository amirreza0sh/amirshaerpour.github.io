Install WordPress on Localhost

Posted on Aug 2, 2026

– XAMPP –

Introduction

In this post, we’ll demonstrate how to install WordPress on your local machine using XAMPP, giving you a full local development environment to build and test WordPress sites before deploying them online.

First, let’s take a closer look at these concepts:

WordPress

WordPress is the world’s most popular open-source content management system (CMS), powering everything from personal blogs to large-scale business websites.

It is built on PHP and requires a MySQL (or MariaDB) database to store its content, making a local PHP + MySQL stack essential for running it offline.

XAMPP

XAMPP is a free, cross-platform local server package that bundles Apache, MySQL/MariaDB, PHP, and Perl into a single easy-to-install stack.

It lets you spin up a full web server environment on your own computer in minutes, which is exactly what WordPress needs to run locally.

Requirements

📌 Note
Make sure ports 80 and 3306 are free on your machine before starting Apache and MySQL.
🚨 Alert
This setup is intended for local development only. Never use these default credentials on a production or public-facing server!

For our demonstration, we just need a single machine (Windows, macOS, or Linux) with a stable internet connection to download the required packages.

Install XAMPP

Download the latest XAMPP installer from the official website and run it:

# On Linux, download and run the installer
wget https://www.apachefriends.org/xampp-files/8.2.12/xampp-linux-x64-8.2.12-0-installer.run
chmod +x xampp-linux-x64-8.2.12-0-installer.run
sudo ./xampp-linux-x64-8.2.12-0-installer.run

Once installed, start the Apache and MySQL modules from the XAMPP Control Panel (or via command line on Linux):

sudo /opt/lampp/lampp start

Setup Database

Open http://localhost/phpmyadmin in your browser and create a new database for WordPress.

CREATE DATABASE wordpress_local CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

Download WordPress

Download the latest WordPress package and extract it into the XAMPP web root (htdocs):

cd /opt/lampp/htdocs
sudo wget https://wordpress.org/latest.tar.gz
sudo tar -xzf latest.tar.gz
sudo rm latest.tar.gz
sudo chown -R daemon:daemon wordpress

Configure WordPress

Rename the sample config file and set your database credentials:

cd wordpress
sudo cp wp-config-sample.php wp-config.php
sudo vim wp-config.php

define( 'DB_NAME', 'wordpress_local' );
define( 'DB_USER', 'root' );
define( 'DB_PASSWORD', '' );
define( 'DB_HOST', 'localhost' );

Congrats! Your local server is now ready for WordPress.

Open up your browser and paste http://localhost/wordpress. The WordPress installation wizard will show up.

Follow the on-screen steps, pick a site title, create an admin username and password, and enjoy!

– Docker –

Introduction

In this post, we’ll also demonstrate how to run WordPress locally using Docker Compose, an alternative to XAMPP that keeps your machine clean and lets you tear down the environment with a single command.

Docker

Docker is a container platform that allows you to package and run applications in isolated environments.

With Docker Compose, WordPress and its MySQL database can be started together with zero manual configuration.

Requirements

📌 Note
Ensure Docker and Docker Compose are installed on your machine.

Setup WordPress

Create a project directory and docker-compose.yml file.

mkdir wordpress-docker && cd wordpress-docker
vim docker-compose.yml

version: "3.8"
services:
  db:
    image: mysql:8.0
    volumes:
      - db_data:/var/lib/mysql
    environment:
      - MYSQL_ROOT_PASSWORD=BwHVuS6j4U03K6hzXfnXVMSp1
      - MYSQL_DATABASE=wordpress
      - MYSQL_USER=ahsp
      - MYSQL_PASSWORD=BwHVuS6j4U03K6hzXfnXVMSp1

  wordpress:
    depends_on:
      - db
    image: wordpress:latest
    ports:
      - "8080:80"
    volumes:
      - wp_data:/var/www/html
    environment:
      - WORDPRESS_DB_HOST=db:3306
      - WORDPRESS_DB_USER=ahsp
      - WORDPRESS_DB_PASSWORD=BwHVuS6j4U03K6hzXfnXVMSp1
      - WORDPRESS_DB_NAME=wordpress

volumes:
  db_data:
  wp_data:

# Run the stack
docker compose up -d

Congrats! Your local WordPress site is now running.

Open up your browser and paste http://localhost:8080. The WordPress installation wizard will show up.

Complete the setup and enjoy!
